# 历史错误观察协调收口

## 当前缺口
PR281阻断纯观察通知但未退役历史安排，coordination-observer仍依据旧成员版本展示blocked。用户要求处理四UPR原协调完整链。

## 方案与边界
新增精确只读check和正式退役入口，绑定coordinationId、group、expectedRevision、配置操作者及原因。事务内拒绝任何非纯观察成员、schedule/occurrence或下游依赖；原任务及已发送/未知通知不改。仅退役无发送许可通知及原错误观察义务，保留来源、完成证明和审计事件。Observer按正式退役终态展示，不直接隐藏行。处理重复提交与版本竞争。

## 验证与交付
定向测试check零写、同群/身份/版本、非观察拒绝、依赖拒绝、四任务零变更、通知未知/已送达保留、重复幂等、看板终态。新feature分支及PR，不能push已合并281分支。安装后通过正式接口处理精确原协调并独立回读。部署流程中的全库扫描精简是已授权相邻工作，不能为本次修复再次机械重复扫描；需要读清原生排空合同后改脚本并测试。
