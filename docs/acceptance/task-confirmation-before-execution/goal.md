# Goal

保证群聊中的任务确认不会在重试或压缩后被空回复绕过，并让可靠确认先于非取消类叶子任务执行。

## Sub goal matrix

| Sub goal | 状态 | 完成证据 |
|---|---|---|
| Task 动作强制非空回复 | 已完成 | `Task动作缺少确认时保持pending且补回复后先写Outbox再创建Task` 通过 |
| Outbox 先于任务执行 | 已完成 | 新建、重开和上下文推进顺序回归通过 |
| 快速取消不回归 | 已完成 | 取消信号在 Task 串行队列释放前触发的并发回归通过 |
| 本地部署与原 Session 恢复 | 进行中 | 待安装、重启和运行态回读 |

## 重大决策

- 所有 Task 动作都要求回复；真正无需回复时必须不产生 Task 动作。
- 非取消动作以可靠 Outbox 为执行前屏障；取消信号保留优先级，避免继续消耗错误任务。
- 不修改任务状态枚举或 storage domain 版本。
