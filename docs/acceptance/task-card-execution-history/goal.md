## 边界与决策

- 不合并仅分析任务，不按相似标题或来源标识合并。
- 使用原生事件的明确关联树。保留每次执行的内部 ID，不迁移或覆盖业务记录；新增查询可从已有事件重建，不引入存储 schema 迁移。
- 执行编号按数据库接受顺序，底层 run 不等于整项执行。
- 卡片组件不改显示；历史入口只放详情，步骤组件复用原结构。
- 默认最新执行；旧链接仍可定位原执行；历史操作只读，当前操作不得被静默转发到另一次执行。
- 本次交付到 PR，不擅自合并或部署。真实业务任务仅只读查询，不重新执行，不发送消息。
