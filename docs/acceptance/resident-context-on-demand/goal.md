# Goal

让常驻会话不再为每条群消息重复接收历史回复正文和全部 Task 历史；仅在确实需要回复或关联任务时按 ID 读取所需上下文，并复核受超长输入影响的最近消息。

## Sub goal matrix

| Sub goal | 状态 | 完成证据 |
|---|---|---|
| 历史回复候选按请求读取 | 已完成 | 普通 Steer 只带候选数，提交前读取完整不可变快照 |
| Task 完整历史按 Task 读取 | 已完成 | 系统提示改为摘要索引，最终关联前读取完整上下文 |
| 代码、预算与协议回归 | 已完成 | round-1 记录全量测试与最近 30 条重放结果 |
| 本地安装、重启与消息复核 | 已完成 | round-1 记录 tgz、插件版本、运行态和最近消息回读 |

## 重大决策

- 候选选择及 8 条/16 KB 上限仍在 Runtime 内完成，读取工具只返回请求创建时已绑定的不可变快照。
- Task 摘要只负责召回，不能直接作为关联结论；完整目标、验收标准、消息和参与人时间线继续保留并可按 Task ID 读取。
- 不为验收向真实业务群制造消息；用当前持久化状态、精确消息回读和最近消息重放核对处理结果。

## 进展

- round-1：源码、安装包、本地部署、原 Resident 恢复和最近消息复核全部通过。
