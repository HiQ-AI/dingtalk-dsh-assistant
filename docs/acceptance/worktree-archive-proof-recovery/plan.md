# 归档保护误拒绝修复

专家审核撤回任务的干净调查目录无同名 origin 分支，但登记 HEAD 是实时 feature/uat2-base 的祖先；旧检查只比较同名分支头，误判未保存。侧栏留白任务的目录及 Git 登记已删除，11 份文档仍在准确登记 HEAD 中；现有同名工作区清单是更新版本，不能替代原件。

只读预检核验实时 origin 公布分支头的提交包含关系，不 fetch、不改引用、不能证明就拒绝。已删目录的文档从登记 HEAD 的普通 blob 取原字节，任务专属归档路径不变，先校验所有源/冲突再写、逐文件摘要回读，最后登记 cleaned。路径、身份、跨任务占用、脏代码、未知文件门禁保持。交付包括定向测试、真实零写预检、PR 合并、本地安装、正式归档及独立回读。
