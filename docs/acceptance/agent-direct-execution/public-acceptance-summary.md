## 已实现

- 普通问答由消息事项执行 Agent 调用受信查询工具，无需创建业务 Task；需要持续交付时使用统一调查阶段。
- 输入、会话、租约、结果与通知持久化；补充续原会话，取消等待真实排空，未知发送先对账。
- 查询按主体与会话范围授权；输出引用须经过独立核验，可纠正的引用错误在原会话和预算内修正。
- 调查等待不冒充阶段成功；前序调查产物通过可信绑定进入工程输入。
- 只读运行资源提供镜像、就绪状态及限定配置字段；日志诊断采用字段投影，不输出任意正文。
