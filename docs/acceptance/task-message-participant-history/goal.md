# Goal

让 Task 和叶子会话保留完整、精确的相关消息与参与人时间线，并让群通知基于这份时间线选择引用目标和多个通知人。

## Sub goal matrix

| Sub goal | 状态 | 完成证据 |
|---|---|---|
| 定义并持久化 Task 消息时间线 | 已完成 | Store 创建、追加、重开、旧数据补齐测试通过 |
| 支持同批多消息对多个 Task 的精确映射 | 已完成 | 多对多 Decision Runtime 测试通过 |
| 由常驻模型选择引用目标和通知人 | 已完成 | 历史引用、多参与人及非法路由拒绝测试通过 |
| 验证兼容、全量回归和本地运行 | 已完成 | round-2 全量 159/159；本地 Web、DWS 与存储回读正常 |

## 重大决策

- 由模型输出每个 Task 动作关联的消息 ID，Runtime 只校验真实存在，不用关键词或“最新消息”推断。
- 通知引用与 @ 对象由常驻模型结构化选择，候选范围严格限制为 Task 时间线。
- 旧字段保留兼容；历史数据只补齐能够可靠回读的消息，不猜测缺失关联。
- `messageHistory` 是可选增量字段，继续使用 storage domain 版本 6；仅增加可选字段不要求破坏性数据迁移。
