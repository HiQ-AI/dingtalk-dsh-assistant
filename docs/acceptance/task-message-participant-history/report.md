# 验收报告

## 结果

round-2 全绿，Task 消息与参与人时间线功能通过本地验收。

## 已验证能力

- Task 按消息 ID 持久化全部被判定为相关的消息、发送人、时间、引用关系和执行轮次，不再覆盖成最新一条。
- 一个 Decision 内支持多消息与多 Task 的多对多关联；每个动作只得到模型选中的相关消息集合。
- 叶子会话和 Task 协调通知均获得完整、按时间排序的 Task 流程。
- 常驻模型可从 Task 历史选择任意相关消息作为回复目标，并选择多个历史参与人；Runtime 对目标和人员做结构化真实性校验。
- 历史 Task 只补齐能够从群消息记录证明的来源，不伪造缺失关联。
- 新字段与已有 storage domain 版本 6 兼容，本地已有状态可正常重启。
