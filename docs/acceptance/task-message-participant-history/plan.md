# 验收计划

## 需求

Task 持久化所有相关消息及发送人；叶子获得完整流程；任务通知不再固定取最新触发人。

## 改动

1. 扩展 Decision 动作来源映射与 Task `messageHistory`。
2. 创建、补充、重开统一按消息 ID 幂等追加时间线。
3. Task 协调提示提供完整时间线，回复工具接收并校验引用消息与多位 @ 对象。
4. 保留旧数据兼容与无稳定发送人时的安全退化。

`messageHistory` 为可选增量字段，不修改现有 storage domain 版本。旧数据只在能用群消息原始记录证明关联时补齐，不从文本信封猜测发送人或消息关系。

## 验证

- Store schema、创建与历史补齐测试。
- 同批部分相关、多 Task、多发送人映射测试。
- 单一引用目标、多通知人、非法路由拒绝和旧 Task 退化测试。
- 全量 `pnpm test`、打包内容与本地运行态验证。
- 用已有版本 6 存储重启，确认无需数据迁移且恢复问题为空。
