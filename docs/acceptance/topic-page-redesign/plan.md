# 话题页面重构验收计划

验证话题索引与详情工作区在真实浏览器中的信息层级、长文本约束、异步状态和窄屏表现。浏览器使用 DSH 容器与 UI primitives 的最小宿主替身，HTTP 数据为本地 fixture，不连接 resident Runtime 或 DWS。

## 用例

- 桌面端话题索引保持窄列，详情占据剩余宽度。
- 长标题、长摘要和连续英文标识不会重叠或产生横向溢出。
- 固定版本详情、消息分页和 Task 话题入口保持原行为。
- 按钮可通过键盘选择，390px 视口无横向溢出。
- 列表与详情的加载、空态、失败重试完整可用。
- 较晚返回的旧话题请求不能覆盖当前选择。
- 左侧话题只展示名称与摘要，不展示话题状态、版本或处理进度横条。
- 右侧始终区分标题与话题摘要，摘要为空时显示明确空态。
- 引用消息默认折叠，展开后分页和错误重试仍保持可用。
