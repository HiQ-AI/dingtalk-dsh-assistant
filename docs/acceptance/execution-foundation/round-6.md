# M2 受管代际目录集成修订

2026-09-23。Windows/Node24.19.0，全部写操作只在临时合成仓库。

首轮实际Controller目录换代测试失败：perform返回的是效果观察的回执信封，调用方读取directory得到undefined；另一个回执丢失恢复测试通过。修订Controller将适配器业务result传给节点，控制账信封及证据继续独立保存。同步Git组合测试断言最终节点产出包含真实commitId，防止只检查object schema漏掉这类层级问题。

修订后定向运行真实Git交付及workspace组合共3项全部通过：A代删除/未跟踪文件保全，源用户改动保全，B代从固定base创建；创建完成但回执丢失后，重开控制账、对账并恢复，只创建一次。此处是控制库worker重开，不冒充整机断电。

独立审查另发现源内名称为 `..managed` 的目录曾被前缀判断误放行。改为按路径段/盘符判断，当前反例返回WORKSPACE_SCOPE_INVALID。新增历史创建成功后目录丢失的回执重投反例：只能复核身份，不能重克隆。全量最终结果见round-7。
