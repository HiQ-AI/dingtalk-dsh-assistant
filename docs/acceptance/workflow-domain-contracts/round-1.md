# 实施与独立复审

基线 d0bb185；源码在独立 worktree 中实施。此轮是开发与纠错记录，最终状态以 matrix.csv 的最后一轮为准。

## 已验证证据

- 共享验收合同的 16/17/32 项正例与 33 项、空白、过长、类型错误反例通过。
- v5 调查定义摘要固定值测试通过；v6 使用 Host 验收 ID，缺项、重复、假引用被拒绝。
- 文件清单拒绝缺项和真实字节摘要不符；文件生成不代替发送独立回读。
- 失败恢复分类未改变自动重试资格和未知效果处理。

## 本轮发现与修正

1. 独立复审复现：调查输出明确不足，Owner 仍可仅用同一结果改评为满足。改为领域合同要求绑定后续新证据，并覆盖后续调查仍不足的反例。
2. 材料容量原先仅在合并原始来源前校验。增加准备后校验，拒绝合并后超限。
3. 只恢复活动 Run 会漏掉后续交接或 Owner 完成所需的成功 v5 前序。增加所需定义集合，真实关闭/重启测试覆盖后续待确认及全阶段成功但 Owner 未完成。
4. 最终清单接纳原先只判断真值。改为严格 true、类型、版本及 Task/需求/计划身份核对，拒绝字符串和错版清单。
5. 首次集成包含旧调查 fixture、查询工具缺少 artifacts.put 等不完整测试上下文，已按真实合同调整；没有删除失败场景。
6. C 盘临时目录空间约 148 MB 导致 SQLite 写入失败。本轮失败批次不算通过；后续 TEMP/TMP 使用 worktree 的 D 盘临时目录，未清理用户文件。
7. 新增任务详情清单断言首次因 Web fixture 未配置 webActorId 得到 null；补齐该测试的受信本机身份后通过，没有放宽生产读取边界。

本轮不声称部署、真实模型语义验收或钉钉外发通过。
