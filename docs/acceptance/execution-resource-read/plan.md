# 执行自读租约及审查补强验收

对应复盘前三项，前置方案见 [spec](../../spec/execution-resource-read.md)。基线为 `99a429fcde279dfe7ac4ddb400ada18c7396ebeb`。

目标：循环查库发现有补证/修订/复审闭环；首次候选审查覆盖测试和辅助代码；执行会话不依赖统筹额外 feedback 即可读取自身当前资源，并拒绝旧绑定。

范围：三个插件实现文件、相关测试、资源工具文档及四个已有个人 skill。个人 skill 位于运行时技能目录，按文件摘要留证，不打入插件 npm 包。新建独立原生工具测试文件是为复用完整 Host 夹具验证服务接线，账本和会话边界测试继续补在原文件。

验证使用真实隔离 SQLite、原生 Agent/Tools/Session 和已安装原生依赖，只有 LLM 响应由脚本驱动；不操作正式控制库、UAT 或真实业务数据库。技能评估使用合成材料，保留每项判断及理由。状态见 matrix.csv，每轮证据分别保留。

部署失败按用户校正归因于部署平台。本轮不修改 Woodpecker 上传/构建流程、平台健康脚本或 Dataset 业务代码；原复盘归因已在原文件更正。本轮交付代码 PR 和个人 skill 更新，不包含插件正式实例安装。
