## 失败与边界

第 1–3 轮最后的零写断言失败。第 1 轮临时夹具未保留完整命令日志，证据不充分；验证脚本已改为失败也在 `finally` 归档，逐用例即时记录。第 2、3 轮失败原输出保留；第 3 轮差异明确定位到 `.git/index` 内容与时间戳。Git `--no-optional-locks` 单独不足，显式禁用 `diff.autoRefreshIndex` 后独立复现及第 4 轮通过，并禁用外部 diff/textconv 防止读取候选时触发额外命令。

所有用例使用本地一次性 Git 夹具，未连接实际数据库/业务服务；夹具已清理。命令日志和历史失败输出留本地，提交仅需本报告、验证配方、必要补丁和紧凑结果。该辅助脚本要求无凭据命令及输出；用于当前检出根目录的有限验证命令，不承担常驻服务管理。
