## 总目标

依据 `docs/spec/task-owner-session-orchestration.md`，让每个业务 Task 拥有一个可恢复的负责会话，接纳同话题补充、组合多个专业流程或日常能力，按目标验收，并统一汇报；保留现有 Host 的持久化、权限、审批、效果对账和通知回读边界。

- 设计文档 T01–T30 的适用场景均有实际验证证据，无未关闭的 FAIL。

- 迁移有无副作用自检、源/目标对账、回退边界；README、部署说明与实际行为一致。
- 代码相关的本地实跑通过，PR 状态与提交内容独立回查；本地部署与真实渠道业务验证分别记录，不用前者替代后者。
