# 普通调查并入任务执行会话

用户批准后实施：Task Owner 直接使用原登记查询能力，Host 保存当前任务及需求绑定的原始结果，不再注册普通调查工作流。最终验收组合原生查询和真实受管操作事实，共享一次语义判断。纯查询任务允许零阶段、零 Run，外部 SQL 和插件批准仍按原生效果记录核验。

创建消息仅持久接纳任务，复用原恢复调度器派发。每任务单 flight/租约，固定四路并发，每条会话完成即串行应用动作；关闭取消并排空。真实隔离服务用例证明慢会话未结束时，两条来源消息已 settled、快任务已 complete/applied，暂停消息仍能取消慢会话。未新增轮询器或队列。

本轮验证同时修正三个旧前提：附件材料的模型投影不能代替 Host 冻结正文生成查询输入；纯查询完成不能依赖成功计划/Run 显示结果或发送通知；仅改报告偏好应读取当前需求及全部验收项匹配的既有最终回执，新增业务目标不能复用旧验收。

## 边界

本轮不恢复已授权删除的业务记录，不创建生产工单或执行 SQL，不向真实群发送测试消息。旧 SQL 验收仅保留历史轮次，不代替本轮测试。部署前需取得完整相关回归与精确包证据。
