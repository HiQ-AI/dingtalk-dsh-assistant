# 验收计划

## 需求与改动

实现钉钉在线电子表格配置、180 秒定时同步、手动同步、严格全量覆盖、完整回读和设置页状态。核心代码、接口、文档和真实目标见同目录 `goal.md` 与 `docs/spec/task-board-sheet-sync.md`。

## 验证层次

1. 纯函数与服务单元测试：任务范围、字段、排序、阶段、转义、单飞、事务命令及回读。
2. 全仓回归和打包：生成 Web client、执行全部测试、检查 tgz 内容和摘要。
3. 真实 Sheet：连接、成功覆盖、失败回滚、行数和旧尾行回读。
4. 本地部署：稳定存储预检、安装文件校验、PID/端口/健康/API/UI 和正式配置回读。
5. 周期验收：连续三个 180 秒周期、任务减少/归档或受控等价数据验证。

## 通过规则

`matrix.csv` 是状态总表。每项必须有独立读回；任何 PENDING/FAIL 时不生成 `report.md`，也不声称整体完成。
