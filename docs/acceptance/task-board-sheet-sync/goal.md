## 总目标

插件支持配置钉钉在线电子表格地址，并由 Resident 纯脚本每 3 分钟将任务看板全部未归档任务全量覆盖到指定工作表；同步状态可见、失败不破坏旧快照，并在用户提供的“小小鹏任务表”完成真实写入与回读验收。

## 完成条件

- 配置页可保存启用状态、表格地址和唯一目标工作表，支持连接检查与立即同步。
- 插件启动后立即同步，之后每 180 秒同步；手动与定时单飞，停止时正确释放。
- 输出覆盖待执行、执行中、等待中、已完成的未归档任务，任务减少、归档和归零后无旧尾行。
- 覆盖由一个严格事务完成，失败或未知结果按回读判定，不用退出码冒充成功。
- 单元测试、本地真实运行、目标表格写后完整回读和连续周期验证均通过。
- README、安装配置说明和运维说明与实际行为一致；形成自包含 PR 并回读状态。

## 范围与约束

- 目标文档固定为 nodeId `14dA3GK8gjN40j3jiE5azAZGJ9ekBD76`，当前唯一工作表为 `Sheet1`（sheetId `kgqie6hm`）。
- 仅同步未归档任务快照；不写历史、不调用 LLM、不创建任务、不发送群消息、不扩大文档分享权限。
- DWS profile、URL 类型、sheetId 和写后状态均来自真实读取；不保存 token，不猜测 ID。
- 当前主检出中的未跟踪文件属于其他工作，所有代码和提交只在 worktree 分支 `worktree-task-board-sheet-sync`。
