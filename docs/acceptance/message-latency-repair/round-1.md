- “三分钟后”样本：消息至澄清送达 219.088 秒；两次 8 步规划均未提交，参数越界和 17 个任务详情读取占满步骤，随后分别等待 8.275/66.404 秒才重试。工具本地耗时只有 129/96 毫秒，不支持“数据库慢导致两分钟”的解释。
