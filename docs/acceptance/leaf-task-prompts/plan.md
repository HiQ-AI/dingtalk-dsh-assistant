# 叶子任务提示词库实施与验收计划

## 需求

保留通用叶子提示词；新增不同任务的提示词配置。系统提示词只注入索引，叶子按需读取并选择当前流程。任务目标变化时可切换流程；压缩和恢复后自动注入已选流程正文。

## 改动

1. 扩展存储和配置接口，提供流程条目的稳定 ID、修订和并发版本。
2. 扩展叶子工具和任务计划/结果协议，持久化当前流程引用。
3. 用动态系统提示区块渲染索引及当前正文，覆盖恢复和压缩后的请求。
4. 增加配置界面的流程 CRUD，并重新生成 Web 客户端。
5. 更新 README、配置手册和运维说明。

## 验证

自动测试覆盖配置、工具、选择、切换、恢复和竞态；浏览器覆盖新增、编辑、启停、删除、错误与窄屏。运行完整测试、Web 客户端构建和前端静态审计。
