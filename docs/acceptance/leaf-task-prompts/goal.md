# 叶子任务提示词库实施目标

## 总目标

插件支持维护叶子通用提示词和多个任务流程提示词；叶子系统提示仅常驻轻量索引，按需读取并持久化当前流程，压缩、恢复及任务目标转换后正确注入当前正文。

## Sub goal matrix

| Sub goal | 状态 | 验收 |
| --- | --- | --- |
| SG1 配置与存储 | 已完成 | 流程 CRUD、启停、修订、持久化和兼容读取通过 |
| SG2 叶子加载与选择 | 已完成 | 首次仅有索引，按需读取，当前选择可持久化 |
| SG3 转换与恢复 | 已完成 | 排查转修复、压缩/恢复后注入当前正文，旧结果失效 |
| SG4 配置界面 | 进行中 | 可访问地新增、编辑、启停、删除并处理错误/并发 |
| SG5 验证与交付 | 进行中 | 自动测试、构建、静态审计和本地浏览器 E2E 全绿 |

## 重大决策

- 具体任务流程不写死在插件；配置保存自然语言正文。
- 当前任务类型使用流程引用表示，现有 `workType` 不作为流程定位依据。
- 主会话负责协调，叶子负责执行与验证，Host 负责通用状态和版本一致性。
- 当前流程正文由动态 system prompt 区块注入；压缩和恢复不依赖历史工具结果。
