# 工具调用恢复验收目标

## 总目标

让 Resident 工具调用错误可修正、并发冲突可恢复、已提交副作用可确认且不会重复执行。

## Sub goal matrix

| 子目标 | 状态 |
| --- | --- |
| 参数错误返回精简结构 | 已完成 |
| 路由 stale/unknown 可恢复 | 已完成 |
| 回复重启后可读取回执 | 已完成 |
| lossless JSON 边界回归 | 已完成 |
| 本地运行与业务 E2E | 待执行 |

## 重大决策

- 复用 RouteHistory 和 Outbox，不新增独立请求状态表。
- 未找到回执的未知请求只返回不可用状态，不自动重放。
