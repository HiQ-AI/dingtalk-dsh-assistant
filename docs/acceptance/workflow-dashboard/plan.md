# 工作流与配置浏览器验收

日期：2026-10-13。目录范围依据 `docs/spec/workflow-dashboard-catalog.md`；追加配置范围依据 `docs/spec/workflow-managed-configuration.md`。

## 证据与边界

运行真实 React 18、完整 Observer 源码和独立 Edge headless。DSH slot 与 UI primitive 由最小语义宿主替身提供，所有运行时 API 均被本地 Playwright route 截获；未列入夹具的网络请求一律拒绝。目录模式不允许任何写请求；配置验收将只允许明确的夹具变量与绑定 API，记录请求方法/路径，不记录秘密请求正文。

`matrix.csv` 按用例与轮次记录实际 PASS/FAIL；`NOT_RUN` 仅表示新增范围的计划用例，不能计入验收通过。各轮独立保留，不覆盖失败证据；截图放 `docs/tmp/workflow-dashboard/round-N/`，不入库。目录与配置浏览器范围已在 round 13/14 同源码通过；整体交付待主验证与审查汇总后再生成 `report.md`。

## 目录用例

验证导航位置、进入后读取、外部/工程/交付/内置目录、列表与详情、节点顺序与职责、未知版本与未知节点、不可用原因、文档链接、本次任务的实际绑定、归档任务入口和返回选择/焦点、加载/错误/空/禁用、刷新保留、过期请求取消、慢请求跨自动刷新去重、1440/390 布局和键盘。反例任务只有同名文本没有 workflowId/stage 绑定，应不出现。

## 配置新增用例

1. 「配置」紧邻「工作流」，页面独立读取；服务未启用、空列表、加载失败与重试明确呈现。
2. 普通 text 变量创建、回读、编辑；name/kind 创建后不可修改；表单提交 expectedRevision，成功采用返回的新版本。
3. JSON 变量校验及错误保留输入；字段与格式均走明确合同。
4. secret 创建与替换默认遮蔽，显式切换可见；列表/读取/成功回执不暴露秘密；已有秘密的空输入不代表删除，不提供降级为普通变量的入口。
5. 普通失败与 409 CAS 冲突保留当前输入；重新读取采用明确操作，不悄悄覆盖草稿。
6. 从目录选择工作流并绑定 alias → 已存在且启用的变量；工作流详情展示别名、变量名、类型、版本，可跳转配置项。
7. 停用有后果说明与页面内二次确认；取消不产生写请求，确认后展示停用状态。历史版本保留由后端定向测试证明，UI 不伪装成删除或即时撤销旧执行。
8. 离开未保存表单提供页面内保存/放弃操作，不使用 browser alert/confirm/prompt；失败与取消不丢输入。
9. 页面/选中项切换不接受过期返回；刷新和重试保持既有浏览上下文。
   保存仍在进行时，从工作流引用打开另一个变量，应在保存完成后继续这次跳转，不吞掉目标或回到旧变量。
10. 1440/390 宽度、键盘操作、无未授权外发；只允许夹具 `PUT /config/workflow-variables/:name`、`POST /config/workflow-variables/:name/enabled`、`PUT /config/workflow-bindings/:workflowId`。

后端持久化、跨流程授权、冻结旧版本、原始文件移动后实际读取及 secret Host 边界由专门单元/集成测试出证；浏览器夹具不替代这些证明，也不替代部署或钉钉业务 E2E。

## 生产消费闭环增量

工程 v25 未授权数据库工具，因此仅 connector 实现不能证明既有流程可使用配置。工程 v26 的方案分析节点为显式迁入且已授权的托管 DB 资源提供原生只读工具；实施节点保留原两个工具。必须验证真实新工程定义、当前节点会话注册与工具调用，Host 冻结 scope 与普通/secret 分路读取；无映射、无资源权限、旧 v25 均不获得此新能力。

历史 v25 的定义摘要、恢复、验收及修改仍需回归。配置更新后旧 Run 读冻结版本，新 Run 采用更新，来源文件移动和 Host 重建不影响读取；来源映射、scope 或租约失效必须拒绝。受控模型与数据库替身允许用于驱动原生会话和协议，但不能将其表述为真实模型或真实数据库业务验收。
