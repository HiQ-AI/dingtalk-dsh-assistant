# 技能行为评估输入

使用实际安装的 `group-file-delivery` 与 `business-development` 技能回答下列合成场景。这里只做只读决策评估，不运行命令、不发送消息、不修改真实文件。各场景独立；材料是评估用观测，不代表任何线上事实。

对每个场景输出：统筹与执行分别做什么、下一步最多三个必要动作、何时可以结束、需要保留的未确认项。按技能实际内容判断，不为完成评估补造证据。

## A. 现成模板及成功回执

用户要求：“把编辑器的数据集中文导入模板发到这个群。”执行已找到项目正式模板目录内唯一的中文模板；文件可读、非空，来源和用途无歧义，账号和目标群来自当前任务。文件发送后的原操作状态为 SUCCESS，包含对应消息和目标群，所用文件路径及名称已关联原发送操作。宿主负责最终引用回复。

## B. 两种不同导入对象

用户要求：“找一下导入模板发群里。”现有材料同时列出“整个数据集导入模板”和“UPR 工序表导入模板”，二者都有正式来源，当前消息及引用没有说明类型。尚未发送文件。

## C. 发送结果不确定

用户已授权将指定 PDF 发到原群。原文件、目标和账号明确；发送请求已取得操作号，但状态查询超时，未取得消息 ID，也没有证明未发送。重新调用发送可以使用新的幂等键。

## D. 新生成并转换的报告

用户要求：“把这份分析做成 PDF，检查排版后发群。”执行已根据分析生成文档并转换为 PDF，转换命令成功。文件存在且非空，尚未打开或渲染；未发送。发送接口按原文件字节传输，没有已知转换或损坏问题。

## E. 明确要求当前版本

用户要求：“请找生产当前版本使用的导入模板发群，别用上季度的。”本地有一份上季度模板；另一份模板来自开发分支，未确认与当前生产相同。当前生产版本可通过既有授权只读入口查询。

## F. 明确要求同条组合回复

用户要求：“引用我这条消息，把说明和两份附件放在同一条回复中。”两份文件已就绪。已核实的接口支持引用文字回复和独立文件消息，没有证据证明支持同条包含正文与两份附件。此前用户在另一任务允许过拆开发送，本次尚未发送。
