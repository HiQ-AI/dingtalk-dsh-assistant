## 总目标

- 运行数据和源码共同支持故障分类，明确反证、样本范围与观测盲点。

- 固定节点职责、传参、校验、产出、授权身份和故障恢复规则；给出脚本化边界。
- 明确删除、保留、替换的现有模块和分批迁移步骤，以真实业务与时延/成本验收。
- 设计、实现和生产改善分开记录；本轮完成实现后按runbook部署本地，验证消息与任务流程，不重放历史外部动作。
