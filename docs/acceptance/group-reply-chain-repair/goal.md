# 群消息引用回复链路修复目标

## 总目标

消除 `group_decision_submit` 对已提交请求的冗余观察声明和预期 stale 的失败卡片，同时让普通群 Decision 回复完整进入原生引用回复链路，且不削弱新 Steer 到达时的零副作用安全门禁。

## sub goal matrix

| 子目标 | 状态 | 完成条件 |
| --- | --- | --- |
| SG-1 观察协议纠偏 | 已完成 | 已提交普通请求自动计入观察，真正漏观察仍被拒绝 |
| SG-2 stale 正常化 | 已完成 | Decision 与 Task 通知的 stale 均返回结构化结果而非工具失败 |
| SG-3 引用路由补齐 | 已完成 | 普通 Decision 将当前入站消息及发送人传到 Outbox 和 DWS reply |
| SG-4 同根因回归 | 已完成 | 单条、多条、recheck、附件提示、Task 通知和缺失发送人均覆盖 |
| SG-5 本地交付 | 已完成 | 测试、打包、PR、本地安装与运行态分层验证完成 |

## 重大决策

- `submissions[].requestIds` 中的普通请求天然视为已观察；顶层字段仅补充其他已审阅 pending，兼容重复列出。
- stale 是无副作用的乐观并发结果，不是工具执行异常；未知 ID、错群、重复 ID 等仍是错误。
- 普通 Decision 引用本 submission 中最新且具备稳定发送人 ID 的当前入站消息，不引用它所引用的历史消息。
- 引用路由元数据缺失时保持普通发送，不猜测发送人。

## 重要信息

- 现场首提失败后同 turn 重试成功，Outbox/DWS 最终 sent；本轮修的是多余失败面和引用路由退化，而不是虚构一次最终消息丢失。
- 本地运行态已包含另一项审批事件改动；部署使用该分支与本修复的临时集成包，PR 分支仍只包含本次修复，避免回退运行功能或污染改动范围。
