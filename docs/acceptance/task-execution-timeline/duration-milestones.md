# 区段耗时与阶段成果刻线

基于已合并 PR194 的 main 60989545fe8b1bf4229d96f64dc299b0fd6731a5，新分支 feat/timeline-duration-milestones。

仅 Observer 任务详情展示变化，无新增采集、存储或任务执行行为。每块时长取该区段自身起止；进行中随 now 更新，终态固定，不计完成至重开的空档。总览解释为本次处理历时，人工介入为等待历时，执行区段为执行历时。宽条名称和时长同排，窄条优先时长；完整信息支持悬停/聚焦及折叠明细。

成果复用持久 recordedAt 与 summary，在所属会话行按全图统一时间轴定位。细线 1px × 28px，贯穿 22px 色带，上下各超出 3px；不改行高或时间位置，无圆点、数量角标、横向/纵向避让或缩放。不同时间各自绘制，完全同刻共享位置；18px 命中区可查看附近成果各自准确时间和内容。运行/人工等待末端线未恢复。

预览包含区段中间成果、相距 3 秒的密集成果、完全同刻内容及普通成果。桌面/390px 窄屏实测六个刻线中心与对应时间比例误差小于 0.001，并验证全部 y 相同、上下各 3px、无裁切。检查涵盖并行、空档、完成重开、固定/实时耗时、历史缺失、恢复、长名、键盘、失败重试、深色/强制颜色和对比度。

预览为合成数据，使用真实 React 与完整 Observer 模块，API 全拦截；未连接生产库、真实模型、Windows 宿主或钉钉收发。本次云端仅提交合并，部署另行协调。
