# 时间范围导航器预览

本方案替代未提交的长空档折叠，不再使用非线性断轴。全量概览以真实线性时间显示已有活动区段，浅靛蓝半透明选区，中部平移、左右手柄改变范围。原生Pointer Events和指针捕获支持鼠标/触摸，不新增依赖。按钮slider可键盘方向/Home/End操作，Shift大步；手柄不能交叉。

默认最新1小时，短于1小时全部；运行右端跟随当前时间，终态取实际最后结束时间。手动选区是绝对时间，刷新不回最新；“回到最新”显式恢复跟随。所有主图行和成果共用选区，范围外区段不画，交叉边缘裁剪但实际耗时和浮层始终取完整原时间。无数据改写，不补造阶段或人工记录。单一body顶层tooltip及空人工行不撑高修复保留。

隔离浏览器覆盖短任务全部、长任务最新1小时、真实指针平移和双端缩放、边界/最小跨度、键盘、刷新/时钟保持手动历史、恢复最新、裁剪保留6分钟真实耗时、终态右端固定、390px拖动和无页面横溢出。截图 range-navigator-desktop.png、range-navigator-narrow.png。预览全为合成数据和隔离API，未连接生产模型或钉钉，未部署。
