# 第三轮：独立复审与修复

第二轮测试通过后，独立复审发现 C05 尚有两个边界，故第二轮 C05 以 FAIL 记录：局部撤销可能影响其他任务仍需遵守的条件；同一批次重复撤销同一条件会在第二次查询时失败。

- 增加原文范围校验：局部、不确定或保留其他条件的请求不能废止整条共享条件，即使模型误报整话题也拒绝。
- 同批次一致的重复撤销幂等处理；不同 actor、quote 或 scope 的冲突撤销整批回滚。
- 增加以上定向回归，并补充话题分页 revision 过期断言。
