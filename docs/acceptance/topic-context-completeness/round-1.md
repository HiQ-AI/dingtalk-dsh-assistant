## 找到并修复的问题

- 第九候选新增反例最初失败：`candidateCards` 的旧八条硬限制在分页前抛错。改为目录容量门禁，八条作为 R 普通候选页大小；明确引用保留在保护集合。两项分页测试随后通过。
- 长材料原先首尾投影会省略中段。现在小材料给全文；大材料逐页提取逐字引文，Host 检查原文匹配与覆盖，必要事实超限或不确定则零派发。临时失败保留已完成页继续恢复。
- 上下文版本校验只覆盖话题输入。增加上下文、任务要求/控制/授权/Run状态及节点产物的接纳事务校验。
- HTTP trace 对不存在对象曾返回 200/null；新增契约测试发现后修为 404。
- 迁移脚本只锁主库不足以拒绝空闲在线写者。补持有运行时独立 owner 锁，并核对七张原表摘要、备份和每条事实身份。
