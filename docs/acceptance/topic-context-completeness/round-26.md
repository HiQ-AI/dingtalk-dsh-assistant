# 第 26 轮：复用已有开发分支

## 范围

落实用户追加规则：提测 PR 指向明确的 UAT 分支；开发使用原任务已有开发分支，从远端最新提交创建独立工作目录，没有已有分支才生成新分支。

## 实现

- 新流程 v12 从同任务或受信重执行来源的工程记录确定唯一开发分支。明确来源不存在、归属错误、多分支歧义均阻断。
- 新记录保存明确仓库身份；旧配置变更时需成功推送记录的精确 remote/ref 证明，失败或其他仓库/分支记录不放行。
- 冻结远端提交，取回该提交；准备及实际创建目录前再次核对。独立目录 HEAD 为 detached，源工作目录不切分支。交付继续推到原开发分支，精确 lease 阻止并发覆盖。
- 同任务后续修改及重发维持分支；重发不能把复用分支起点重置到 main。
- 目录节点记录路径、开发分支、复用/新建结论、UAT 目标。新分支尚未推送时明确显示“待提交推送”。v11 及更早定义仍使用原 factory。
