# 同库任务归档

任务正文和历史始终保存在同一个 SQLite 文件。`task.archive` 沿用原有 completed/cancelled、执行 drained 等条件；完成不会自动归档，也不新增取消归档流程。

归档在原命令事务内把任务、已 drained 的终态执行、终态操作、acked 唤醒、已交付历史通知和事件移入 `dynamic_archived_*` 表。未知操作、未发送通知、未召回问题、共享来源/群组、协调、调度及锁仍保留活动控制记录。异常使整个事务回滚。

命令回执保留中心主键、digest、原序号和必要决策头；独占该任务的历史正文进入归档表，共享协调回执不搬迁。重放、嵌套协调读取、历史事件和决策页均读取完整历史。归档后的缺失回执正文按损坏报错，不重新执行操作。

活动任务列表默认不扫描归档正文。历史页先从薄索引筛选并选择本页 ID，再按主键读取活动/归档正文；执行控制计数使用现有索引的 state/drained 元数据。

既有已标记归档的数据可使用 `scripts/migrate-observer-pagination.mjs` 的显式离线迁移入口：停用该合成/维护目标、保留一致性备份，并提供匹配 SHA256；默认只读检查，`--apply` 才写。迁移按最多 100 个任务 ID 取批，再在事务中搬迁；不将普通 completed 自动归档。本次未操作真实库。

首次物理归档设置 schema 3 和 taskArchiveSchema 标记，旧二进制不能直接读回，回退必须使用迁移前备份。未部署的外置详情草案格式不作为兼容输入。本 PR 已撤回独立详情数据库、codec 和外置迁移工具。

分表不会自动缩小 SQLite 文件。减少无变化巡查回执写入是独立的控增长措施；真实库压缩不在本次实施范围。
