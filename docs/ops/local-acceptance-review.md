# 评审草稿本地验收

独立受信场景 scripts/local-acceptance-review.mjs 验证真实候选页面中的评审意见草稿。复用只读工具的 origin 与请求校验，不扩展通用查询为任意写操作。

固定配置指定 UAT2、本地后端制品绑定、真实账号配置路径以及 reviewFixture.applicationId/processId。先读取服务端审核上下文和当前轮已提交记录，只有账号确实是未提交审核人时才执行。模型参数为空，不能改变账号、对象或接口。

独立 Edge 浏览器经真实登录后：通过页面添加自定义维度并填写意见→点击保存草稿→离开页面→重新进入→逐字断言 DOM 回显。该路径不依赖审核单存在预设模板。禁止审批提交、分配、附件上传、异源业务请求及响应伪造。独立浏览器上下文中的 localStorage 可以由真实产品操作写入；结束清理浏览器存储、关闭浏览器并注销认证会话，不修改共享审批业务记录。

CLI 为 initialize / execute / cleanup / verify-cleanup，使用 --config 绝对路径并通过 stdin 接收固定候选 runner 输入。prepareSteps 必须先 initialize 再安装依赖，持久记录尚未启动浏览器或认证会话的零资源账。构建失败时可根据该账独立确认零资源；旧 missing ledger 仍拒绝，不回填为已清理。执行只能领取一次初始化账，登录或浏览器启动前先写入未关闭状态，未知结果阻断。清理回执要求浏览器关闭、认证会话退出且业务写入为零；失败不能产生 PASS。本地保存脱敏 ledger 和回显截图，凭据不落盘。

Ledger 按登录、审核上下文、浏览器启动、打开页面、填写、保存和恢复记录阶段；失败仅保存受控错误分类，不记录包含认证信息的原始异常。磁盘空间不足时，通过启动进程的 TEMP/TMP 指向有空间的专属临时目录，不修改系统环境变量。

进程排空回读同时核对 PID 和创建时间。遇到 `COMMAND_DRAIN_UNCONFIRMED` 或 `STOP_UNCONFIRMED` 时，先检查当前任务进程身份及其后代，不能按历史 ParentProcessId 直接终止其他进程。创建时间缺失、快照超过 1 MiB 或原进程仍存活均不能签发通过收据。

该场景覆盖同浏览器上下文的草稿恢复，不代表跨设备同步。测试报告应明确所用真实候选 SHA、后端 JAR SHA、审核对象和判定。现阶段不得用该场景代替尚未实现的后端合并计算场景。
