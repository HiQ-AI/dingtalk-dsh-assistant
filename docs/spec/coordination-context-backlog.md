## 同因补充：文件卡片投影差异

#1349 的 DWS 入站文件文本含固定下载提示尾注，而同 profile 精确 `+messages-mget` 回读仅含文件名与 fileId，且 complete=true、failedCount=0、foundCount=1。插件没有生成该尾注的代码；既有资源规范化仅识别图片引用，不能用于文件文本版本比较。协调资源读取此前将两种展示差异误判成消息版本变化，导致翻译任务要求用户重发文件。

在资源读取版本核对处仅允许已知 DWS 文件卡片的精确尾注差异：其余文本必须完全一致，回读唯一 fileId 资源的 ID 和文件名必须与卡片精确匹配。普通文本变化、文件名或资源 ID 变化继续拒绝，不改持久化原始消息。另需区分 Excel 等协调读取不支持的格式与文件丢失；明确任务授权及附件身份后的正文处理属于执行任务职责。
