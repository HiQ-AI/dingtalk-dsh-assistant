# 叶子通用规范内置与流程折叠

## 目标与现状

当前 Runtime 将 leafSessionPrompt 作为整段通用提示，空值仅有一句兜底；本地配置保存了上一轮整理的通用规范。任务流程编辑器逐项直接展开，九项正文占据大量纵向空间。

## 实现边界

- 在现有 leafSetup 系统提示中内置通用执行规范，复用已有授权、检查点、流程组合、通知与阻塞规则，避免重复堆叠。leafSessionPrompt 只追加用户定制内容，留空仍保留内置规范；不改存储结构，不清除其他用户的既有内容。
- 本地部署后，仅当配置仍与上一轮保存的完整文本一致时清空该重复文本；保持九项流程和所有其他设置不变，先备份后独立回读。
- 在现有 TaskPromptEditor 内使用原生 details/summary，每项默认关闭，摘要显示名称和停用状态；字段、启用、删除仍在展开区域。展开/收起不修改配置，编辑不因名称变化丢失展开状态。
- UI 归属：沿用 client.js 的 React、DSH 语义颜色、边框和输入控件；不引入 UI 库或独立设计系统。原生 disclosure 提供键盘行为，外层不使用 grid 覆盖 details 的内容隐藏语义。仅调整本次两个配置区。

## 验证与交付

验证空配置、新建叶子、自定义追加/清空、恢复无历史时内置规范仍在且主会话不注入；保留现有多流程组合回归。生成 web-client.js，执行全量测试，在浏览器验证默认折叠、展开编辑、键盘及窄视口。按既有授权通过 PR 合并后部署本地，独立核对安装源码、运行态与配置。
