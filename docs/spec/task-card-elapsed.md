# 任务卡片累计历时

卡片底栏保持现有 `fmt(task.updatedAt)` 日期及归档行为，在日期后同排追加 `· <1m`、`· 35m`、`· 4h 3m`、`· 1d 2h`。分钟向下取整，天级显示天/小时，零的次级单位省略。证据不完整或异常显示 `· —`，不显示推测值或补成零。日期和操作不压缩，只有新增时长可以省略，完整值和口径通过提示及无障碍标签保留。

口径复用 `task-execution-timeline.js` 的生命周期：累计各次创建/重开至完成/取消的墙钟区间，含排队、执行、等待和暂停，排除完成至重开空档，不累加并行执行。终点仅来自真实 completion/cancel 回执；当前完成回执需求修订须匹配任务，未来区段及终点显示未知；updatedAt 仍仅表示最后活动时间。重开及前次完成回执缺失、身份或修订不匹配、区间缺失/逆序/重叠时未知。完成后的归档、报告更新和页面时钟不延长已闭合区间。

任务分页响应增加 `elapsedTiming: { complete, closedMs, activeSince }`。完整证据返回闭合区间毫秒总和及当前开放区间起点（终态为null）；未知返回 `{ complete:false, closedMs:null, activeSince:null }`。仅在选完当前页后投影；未重开任务不增加历史查询，重开任务每页批量读取一次wake元数据、一次按主键选择的不可变回执字段，兼容归档回执，不读取执行日志或回执正文结果。摘要目录不增加此开销。现有wake按JSON字段筛选，未引入新索引或数据库迁移。

前端仅在任务看板显示开放区间时建立一个共享时钟；无活动卡片、进入详情或切页后清理。复用原分页刷新，不请求逐卡详情或执行接口。卡片只显示分钟级值，但开放区间按当前时间计算；浏览器时钟早于可信起点时显示未知，不钳制成零。

验证：生命周期与实际分页SQL、缺失/归档回执、格式及归档回归；`docs/acceptance/task-card-elapsed/scripts/verify-browser.py` 加载完整Observer和真实React，检查六状态卡片、日期原样、窄屏、共用时钟、终态固定、刷新失败及键盘归档。HTTP全部隔离替身，宿主primitive用语义适配，不能称已完成真实登录DSH业务验收。
