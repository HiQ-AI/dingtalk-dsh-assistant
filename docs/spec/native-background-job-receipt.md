# 原生后台 job 回执与执行生命周期

显式 run_in_background 已由原生工具返回 jobId，但 collectNativeJob 等待进程终态，且工具调用的进程作用域在返回时终止全部子进程，导致常驻数据库无法被后续工具使用。前台超时提升的短命令继续采用终态收集，不改变其现有合同。

修复只对显式后台调用立即校验并持久化原 job 收据；后台进程归本次 execution 独立作用域管理。工具返回 running 不结算 operation，execution 排空时先停止仍活动的原 job，收集真实终态并结算原 operation，再释放作用域和原生 Agent。进程隔离、归属校验、取消与未知效果保护保留。

验证包括真实后台服务供下一工具访问、显式停止、自动清理、取消排空、前台提升和并行作用域隔离。所有测试使用隔离目录及真实原生 profile。

现场旧 collector 无安全热替换入口，必须先明确停止任务专用 PostgreSQL，使原调用自然产生终态回执；不修改 SQLite、不伪造 terminal、不重放旧启动。部署后由原任务核对停机事实，保留原 pgdata，并在需要时明确建立新的受管服务生命周期继续验证；此为已结算原启动后的后续操作，不能用来规避 unknown。旧 edit 拒绝采用 origin/main 已有前置拒绝对账。
