# 统筹职责与轻量文件交付

## 目标与依据

2026-10-28“查找编辑器导入模板并分享群内”由统筹直接执行 60 次工具调用，未委派执行会话。当前任务提示允许直接业务操作，且原生 preset 暴露完整工具；群文件 skill 又将普通现成文件强制纳入逐件下载验字节流程。用户要求两处一起修正。

## 范围

- 统筹仅做需求理解、委派/纠偏、进度和证据读取、人工介入与最终判断；具体业务操作交给执行会话。简单操作合并为一个执行小目标。
- 在原生工具目录及执行准入落实边界，保留技能和证据只读能力，不凭工具自述的 effectClass 放行任意工具。执行会话继续使用原生能力。
- 更新现有 group-file-delivery 和 business-development skill：普通既有文件找到正确来源后发送、回查原发送状态、简洁说明；生成/转换/异常或显式要求才做对应深度验证。保留授权、真实目标、未知效果不重发等约束。
- 只读核对原任务权限故障和恢复空档；有确证的本仓缺陷才修复，不改用户权限或绕过审批。

## 验证与交付

原生宿主测试验证统筹看不到/不能执行业务工具，仍可读取技能和证据、委派并完成，执行工具不受误伤；覆盖恢复及受限审阅模式。技能做结构、引用及独立场景评估。仅定向相关测试，不触发 CI、不部署、不发送真实群消息。通过后提交独立 PR。
