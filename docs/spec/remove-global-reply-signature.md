# 移除全局回复署名

## 目标与现状

用户要求移除全局署名。当前配置页、运行时配置和发送格式器共同提供覆盖模型末尾署名的能力；任务系统提示同时说明 Host 附加全局署名，造成个人工作区及群职责与发送端分工不清。

## 实施边界

- 删除设置字段、profile 初始化入口、配置读写及格式器的追加/替换逻辑。
- 任务提示明确：公开回复与 requester 问题遵循工作区及所属群的署名要求，Host 不添加或替换。
- 保留原生引用、真实 @、业务安全校验、已有通知不可变性。历史存储字段不再读取使用，不重发历史消息。
- 旧客户端提交已删除字段时明确拒绝并保持其它配置不变；其它 Agent 配置继续正常保存。
- 仅源码与 PR 交付；不修改运行实例配置、不部署、不发送真实钉钉消息。

## 验证

复用现有格式器、设置 bundle、配置 HTTP 与原生任务会话测试：不同群正文署名保持原文，旧字段不影响新通知，完成/状态/提问保留来源引用和 @，模型输入不再声称 Host 附加署名。定向测试与前端 bundle 构建结果记录在验收目录。
