# 任务看板定时同步钉钉表格

## 目标

插件设置支持绑定一个钉钉在线电子表格及其中一个工作表。Resident 常驻进程启动后立即同步，此后每 180 秒通过纯 Node.js 脚本将任务看板中的全部未归档任务全量覆盖到该工作表，不调用模型。

## 方案

- 数据直接读取 Resident Store 的 Task 与群快照，过滤 `archivedAt`，按看板状态顺序及更新时间排序。
- 每个任务一行，输出名称、来源群、发起人、状态、当前阶段、阶段进度、最近进展、等待原因、结果、时间、轮次和任务 ID。
- DWS 严格批量事务在同一请求中清空 `A1:N<工作表总行数>` 并从 A1 写入完整 CSV；写后完整读取同一区域，逐格核对新快照并确认旧尾行为空。
- DWS 写入超时或结果未知时仍先回读；内容已完全落地则记成功，否则保留失败。定时与手动触发共用单飞锁。
- 同步配置及最近运行状态存入 scheduler runtime，与 Agent 配置分离；配置变化不重建 Session。
- 设置页提供地址、连接检查、目标工作表、启用开关、保存、立即同步和最近结果。

## 边界

- 仅支持 `contentType=ALIDOC`、`extension=axls` 的钉钉在线电子表格；普通 xlsx/xls 与 AI 多维表不接受。
- 整个目标工作表是插件托管范围；存在合并单元格或容量不足时失败关闭，不修改其他工作表。
- CSV/命令参数超过当前 Windows 安全长度时本轮失败，不截断任务、不拆成非原子写入。
- 文档分享权限不由插件修改；同步故障只进入独立状态，不把任务 Runtime 标为故障。

## 验证

- 单元测试验证投影、排序、归档过滤、公式起始字符、严格批量写、完整回读、单飞和 180 秒周期。
- 使用用户指定的“小小鹏任务表”验证资源类型、唯一 sheetId、成功覆盖和失败回滚。
- 本地部署后从配置 API 保存正式配置，回读运行状态和目标工作表，并观察连续三个真实周期。
