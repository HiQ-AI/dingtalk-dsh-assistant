# 任务流程组合按需加载

本轮修订：流程类似 Skill，由叶子结合当前任务、目标、授权和剩余阶段语义匹配索引。允许多个流程组合，不设业务类型映射或固定组合数量。

现状有两处不符合这一行为：`load_task_prompt` 读取后还必须调用 `select_task_prompts` 才能恢复注入；选择数量被限制为 5。

改为加载成功即将 ID/修订合并到 Task 当前流程集合，相同 ID 去重并更新修订。保留 `select_task_prompts` 作为可选的集合调整工具，用于移除已不适用的流程；它不再是每次加载的前置或后置必需步骤。加载与调整都在 Task 原子更新处核对输入版本和状态，避免迟到操作污染新目标。

每次构建系统提示均提供轻量索引和当前已加载正文组合；压缩后无需依赖历史工具结果。恢复的集合是当前上下文，不是固定任务类型：目标变化沿用既有清空机制，由叶子根据新目标重新匹配，阶段推进可按需补充和移除。保留现有单条正文与索引体积校验，不为语义匹配增加硬编码规则。

验证：超过 5 个流程的增量加载/恢复、重复加载去重、选中子集后的正文移除、新目标清空与重新匹配、迟到加载/调整拒绝。仅改变 Runtime 与文档，不改变设置界面和用户实际提示词配置。
