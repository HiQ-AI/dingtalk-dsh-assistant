# 暂停独立协调会话

用户要求从代码层面跳过整个独立协调会话功能，等待设计重新确定，不新增开关。

当前 Host 在 task-session-service.js 装配 independent-coordination-service，群路由可将 source unit 交给协调服务，恢复轮询还会消费任务事件、扫描定时安排、派发命令及准备通知。因此仅停止新模型调用不足以暂停功能。

修改边界：Host 不再装配独立协调服务，不开放协调来源准入，不恢复或派发历史协调安排，不允许协调阶段重试，不发送协调通知。普通 Topic 路由、任务 Owner 与执行会话、Web 任务入口保持原路径。历史协调账与来源独占身份保持，不删除、不伪装完成、不转交旧链；只读观察入口保留。

验证：使用隔离原生 Host，配置仍为 enabled=true 时验证普通消息继续处理、协调模型零调用、历史待执行协调成员和通知保持不动、恢复和重试不能重新启动；验证 Web 创建和续办仍可用。只声称源码与隔离测试结果，不自动部署或发送真实业务消息。
