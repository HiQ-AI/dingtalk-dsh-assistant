# 任务步骤时间线调整

## 依据与目标

用户提供执行记录截图，要求学习紧凑的纵向步骤组织。当前实现将步骤名放在固定 220px 列，正文分离，标题和步骤间留白过大。

## 实施范围

- 28px 编号圆点和连续细线串联步骤；编号始终保留，文字状态不只依赖颜色。
- 每步标题与耗时同一行，耗时靠右；正文紧跟标题，桌面使用标签/正文对齐，窄屏自然换行。
- 顶部压缩，步骤进度条铺满内容区；百分比只表示已完成步骤数，不推测剩余时间。
- 保留真实 outputRef 的只读分页、失败重试与懒加载。补充既有明确字段的材料正文、文件清单、变更及检查结果；不遍历任意对象，不展示工具参数、日志或 JSON。
- 校验节点返回原结果时照实展示，不捏造独立校验报告，不改变执行/校验规则。

## 验证与边界

实跑定向单元测试与隔离浏览器，观察桌面/390px布局、右侧耗时、分页和空状态。按既有 runbook 安装本地并只读核验，不重跑任务或发送消息。
