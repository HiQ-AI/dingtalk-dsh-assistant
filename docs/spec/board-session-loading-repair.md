现场/state/groups 28068ms、3367054bytes，其余12–1303ms。mailboxes按全部历史message.list分页，逐Run调用message.run，读取nodes/executions等大字段；前端Promise.all等待最慢接口且每5秒并发重叠。保持既有历史可见，新增同页轻量mailbox投影：仅请求/受阻事项/失败答复，不读取模型输入输出，消除逐Run跨worker往返。前端单次刷新共享promise，不重叠或旧值覆盖。

当前协调会话header.cwd为Agent目录，原生日志danger-full-access/never和群名正确；原生session/list对大继承历史的离线会话返回projections空，准备阶段dispose使其离线。因此常驻会话空闲时保留只读展示挂接句柄，前置拒绝模型步进；运行前释放展示句柄并按既有工具与租约重新恢复，关闭时排空全部句柄。组API提供当前绑定，页面入口只打开当前协调会话。

验证：同页投影与旧状态输出等价、不读大节点、分页跨200保留全部历史；前端慢刷新去重、错误后重试；原生准备/运行/取消/关闭租约和历史继承；实际本地接口前后耗时、真实浏览器标题权限与入口；按runbook部署回读。
