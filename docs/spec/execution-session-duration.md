# 任务卡片执行会话时长

仅在任务卡片的执行会话列表展示累计实际运行时长，左图标、中间名称、右时间值保持单行；名称超长以 ellipsis 省略并提供完整 tooltip，320px 也不换行；原状态文字位置仅显示时间数值，移除可见状态文字和“时长”前缀；状态含义由原图标的 tooltip/无障碍标签保留。复用 observer 的 fmtDuration，不增加明细请求，不修改其他页面。

动态账本的 runTiming 为 Host 管理的元数据：recorded 表示累计记录完整，elapsedMs 为已结束运行区间之和，startedAt 为当前领取执行的起点或 null。新分派初始化为已记录的 0；execution.claim 开始区间，首次 execution.result 或 execution.drained 关闭区间。结果后的排空等待不计；无结果排空后重新排队不计。取消请求尚未排空的时间仍属于运行区间。

execution.continue 和 provider 重试复用原执行/会话，保留累计值；下一次 claim 才恢复计时。终态固定，重复结果/排空不会重复累计。仅增加 JSON 记录字段，无数据库 schema 迁移或历史回填。

历史无 runTiming 一律显示“—”，tooltip/无障碍标签解释“时长未记录：缺少完整的实际运行计时证据。”，即使后续续办也不假装拥有完整累计值。Host 重启时，存在未结束计时区间则将 recorded 置 false 并清除 startedAt；恢复确认排空时不以恢复时间冒充实际终点。已收到结果且区间已关闭的记录保持固定。时钟倒退导致负区间也标为未记录。

浏览器只在完整且存在活动区间时每秒刷新显示；缺字段、未知区间与终态无计时器。验证使用隔离 SQLite/合成浏览器 API，不接触真实业务或部署实例。
