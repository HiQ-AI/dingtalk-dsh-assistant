## 验证与记录

### 本地验收与 UAT 合并门禁

本轮目标为 dataset UAT3、dataset-web UAT2，复用原 PR 与开发分支。UAT 合并必须回读同任务成功的 v11/v12 工程 Run：本地验收逐项覆盖任务条件，候选、计划、提交树、PR head、目标环境一致，数据清理和进程停止均已确认。Host 由不可变工件生成 localEvidence，模型不能提交通过结论；合并执行前重新回读并核对证据摘要。

GitHub 检查与本地业务验收分开：Host requiredChecks 可为空，但必须回读目标分支的真实保护及规则集，与配置取并集；读取失败不当作无规则。非空检查必须在精确 head 上成功。保留 PR/base/head 漂移、合并树和部署制品验证，不发布占位 GitHub 检查。新增 UAT 定义版本，历史及 main 定义保留原契约，避免恢复时改写旧定义。

每个受信 `uatMerge.targets` 条目还必须配置非空 `requiredScenarioIds`，列出本次交付要求的真实本地业务场景。Host 只对照本地验收回执中的 scenarioIds，不接受混合构建 checkIds，也不接受通用只读场景冒充业务回归；所有任务条件仍须完整覆盖。

### 冻结 UAT 基线后验证待合并树

旧开发分支落后 UAT 时，新任务使用 v13。Host 固定开发 SHA、目标 UAT SHA 及可信原任务开发起点 taskBase，并校验 taskBase 是当前开发 SHA 的祖先。仅重放 taskBase 之后的开发差异到完整 UAT 树，不能把旧开发分支从 main 继承的无关历史一并提测。Git 2.39 通过两个固定身份/日期、共同父为 taskBase 的虚拟提交表达三方输入，再运行原生 `git merge-tree`；虚拟提交只用于对象计算，不进入最终父链。缺 taskBase 时拒绝，不回退整分支合并。

独立工作目录 HEAD 保留开发 SHA，索引和文件来自冻结合并树。非冲突的 UAT 新增、删除和修改由 Git 保留，不交给模型重写。仅同一路径的 UTF-8 文本内容冲突可交给模型；新增、删除、rename 和二进制冲突明确拒绝。冲突路径还须在既有读写范围内、被实际读取并纳入修改方案；验证前不得残留冲突标记。PR 文件清单按 UAT SHA 到验收 tree 计算，不把基线同步差异冒充任务改动。

提交使用固定开发 SHA 与 UAT SHA 作为父提交，tree 严格等于验收候选。目标分支变化时须重新冻结与验收，不能复用旧树通过状态。工作目录准备版本 2、Git prepared 版本 2 和工作流 v13 仅用于新任务，旧 v1/v12 及更早冻结定义继续按原规则恢复。

正式入口最小方案为 `POST /tasks/:oldTaskId/rerun`：新建 taskId，并以 rerunOfTaskId 关联原任务；记录真实 Web 来源、配置的 webActorId 及原始请求，不伪造 IM。actor/原任务/requestId 绑定幂等身份，同正文返回同任务、冲突正文返回 409。请求必须显式给出 UAT 与后继流程。接纳及恢复使用同一持久记录，报告固定留 Web，通知准备、发送、恢复均禁止继承原群外发。

在现有 goal.md 增加 SG15，验收矩阵新增两任务的开发/业务验收/UAT交付及入口安全反例。先只读完成入口、业务场景、UAT 资源三项审计，再实施必要补齐。详细本轮结果写 round-25，实际没有通过的阶段保持未完成。

## 开发分支复用（用户追加）

重执行保留独立任务身份，但复用原任务已登记的开发分支。通过同仓库、同所有者的持久记录核实归属，唯一分支存在时冻结其远端最新提交，从该提交创建独立 Git 工作目录；没有已有分支才生成新分支。创建目录前再次核对远端，提交推送使用精确预期 SHA 防止覆盖并发修改。提测 UAT 分支仅作为 PR 目标，不作为开发分支。节点产出显示目录路径、开发分支及复用/新建结论、提测目标分支。

### 旧 PR 原位纠正与目标基线

只有原任务成功 PR 效果账提供唯一的仓库、开发分支、PR 编号、旧目标分支和 operationKey 时，新任务才冻结并复用该 PR。正式 PR 效果在发送前两次读取编号、OPEN 状态、当前候选 head SHA、旧 base 和标记；同开发分支存在另一 OPEN PR、旧 PR 已合并或身份不符时停止，不新建重复 PR。修改只通过效果网关执行 `pr edit --base`，写入本轮正文与标记后独立读回；回执丢失只读恢复。GitHub 此操作不提供原子 head/base 条件写，本实现不能宣称消除检查与写入之间的竞态；发送后身份变化保持未知，不自动覆盖。
