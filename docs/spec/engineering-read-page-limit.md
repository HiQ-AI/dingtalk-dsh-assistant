# 工程读取分页上限纠正

本轮前端会话对合法组件请求 limit=19000，Inspector 上限为16000，但工具未说明该上限，抛出参数异常后终止会话。

仅对正安全整数且超过当前操作上限的 limit，经过参数、任务、快照及读取路径准入检查后返回 invalid_limit、maxLimit 和 suggestedCall，不读取正文、不静默截断。read 上限16000，list/search 上限200。负数、非整数、越界路径及身份错误仍拒绝。工具说明同步这些限制；原生会话错误停止规则不变。

验证真实 registry 的超限与纠正、越界超限仍拒绝，以及原生会话收到结构化提示后能继续合法读取和提交。失败历史保留，部署后重新发起前端验收。
