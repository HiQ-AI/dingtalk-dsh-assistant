# 领域合同本地部署与模型验收

用户追加要求部署本地并验证。部署源为 PR #141 的已验提交 7d064d4，现有实例使用 D:/dsh_home/profiles/web、runtime-v2 控制库及 v9-pr116 Domain。本轮仅更新 Assistant，Observer 的差异为换行；不合并或发布版本。

复用现有受控部署脚本。当前查询配置原样提案经 check 确认 changed=false/writes=0，保证配置不变；执行维护排空、封存停机许可、独占锁、完整备份和一致 SQLite 验证、原生安装及源码字节核对。启动时保持维护，回读健康、历史、配置及认证 Web 后恢复派发。

新增验收脚本放在本特性现有 scripts 桶，因为现有协议测试使用模型流夹具，不能验证安装代码调用实际提供商。脚本只导入正式 profile 已安装模块，使用实际 Codex Connect/LLM 及当前模型配置，在全新本地目录建立独立 SQLite、工件与真实文件效果。调查输出和 Owner 候选固定以可重复触发门禁；领域业务检查使用真实模型，不把该脚本称为完整真实 Owner/调查会话验收。

正例为实际写入并读回调查记录，最终 Owner 完成和 accepted 业务清单持久化后重开读取。反例为调查明确未修复生产故障，随后仅保存备忘录；强制提出完成候选仍应被领域检查拒绝且无完成清单。模型必须返回有效语义判断，不能把缺配置/超时当作反例通过。二者不接入正式消息控制库、不发钉钉、不访问业务库或部署资源。

另对在线实例验证容量拒绝无任务增量、目录合同、任务历史和延迟存活。记录安装/模型/控制面及未测渠道边界，不以健康或协议测试替代业务验收。
