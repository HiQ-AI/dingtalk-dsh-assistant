# 发信箱送达、替代关系与时间

现状：前端先判断 supersededByOutboundId，覆盖 sent/delivered；固定撤回提示没有核对替换消息，且当前任务运行时不执行旧群消息替换撤回。表格未展示时间；sendStartedAt 来源为通知创建时间，deliveredAt 为回读观察时间。

方案：送达优先于替代关系，真实撤回结果仍保留。替代关系在消息附加信息单独展示，不承诺自动撤回；独立筛选替代关系。新增发送时间列，仅使用 verified receipt 中原消息 createTime；缺失显示未记录并标注独立回读确认时间。新增回读只在身份/正文校验成功后保存有效 ISO 时间。历史通知不补写、不重发、不撤回，不迁移数据库。

复用 web-client.js 的状态函数、原生表格、Button、时间格式；复用任务回读及发件投影，不建立第二套状态账。更新 README、DESIGN 和当前原生部署 runbook。定向测试覆盖已送达且被替代、未发且被替代、真实撤回、筛选和时间真实性；本地原生双包部署后检查已知旧通知、筛选、历史发送时间缺失、回读时间、刷新与窄屏。零写预检、包摘要、排空、新 PID 和健康独立核验。
