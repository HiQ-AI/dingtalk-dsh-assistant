# 任务步骤产出展示

在编号步骤的耗时之后直接显示业务产出正文；进入任务详情才加载，列表不读取每个工件。首段最多 1200 字，长内容点“继续阅读”分页追加。展示摘要、正文、发现、限制及准备阶段的任务要求；不渲染原始 JSON、工具参数或任意对象字段。没有文字产出明确提示；读取失败可重试。

复用 workflow service、artifacts.read、HTTP 路由及 observer。新只读接口按 Task → Run → nodeRunId → outputRef 校验关联及配置群范围，客户端不能指定任意文件。分页固定 outputRef，结果更新后旧页拒绝。React 原文文本渲染，不执行 HTML。

验证跨群/跨任务/不存在节点/过期引用拒绝、正文分页、无技术字段；浏览器默认正文、展开长文、失败重试与窄屏、未打开任务详情不读取产物。定向实跑后更新本地两个插件，回读真实节点产出。

用户补充：取消页面级左右分栏，以通栏步骤为主体。每步左侧编号、名称与状态；右侧先耗时再产出，内容直接展开。任务目标在上、最终结果在下；窄屏改为上下布局。
