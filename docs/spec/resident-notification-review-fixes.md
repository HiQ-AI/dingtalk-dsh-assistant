# 常驻通知复查缺口修复

基线：47a47e6。复查已确认回读绕过、流程版本竞态、异常上报被计划门禁阻断、长原文突破预算及流程漏选复核缺口；现有 201 项测试未覆盖这些反例。

实现分工与边界：

- 发件箱删除组织未授权时跳过回读的路径，保留结构化错误及重试观测；看板区分失败与等待回读，不发送真实测试消息。
- 复用任务协议模块中的当前流程引用校验，计划、阶段、审阅及最终写入均核对启用状态与 revision；配置更新不能依赖叶子重载才使旧计划失效。
- 范围冲突、风险和证据缺口可在无计划、拒绝或过期计划下报告，保留执行版本与进度保护，不能利用异常上报推进或完成。
- 审阅采用硬预算、原文续读和整体请求分页；保留任务流程索引与选择依据，审阅者可读取未选择的候选并要求重新规划，不硬编码业务类型或强制所有任务选专用流程。
- 完成审阅和通知草稿仍一次模型请求；请求发起、拒绝或失败时记录事件，避免只在完成后补记起点。

验收：将上一轮反例改成正确行为回归，覆盖改版/禁用/删除/审阅竞态、异常报告不推进、长原文续读、无流程及多流程、发件箱保留 pending 与错误展示。运行全套测试并按本地 runbook 验证安装/启动/访问；DWS 真实投递因用户明确暂缓组织权限而保持未验证。
