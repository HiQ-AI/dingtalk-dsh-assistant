# 自身通知迟识别后的来源退役

日期：2026-11-05。目标入口：`docs/acceptance/topic-routing-quality/goal.md` 的 SG4。本文是新增持久化合同实施前的决策快照，不记录事后验收结果。

## 问题与证据

当前14条正常业务来源仍等待路由屏障解除。正常恢复必要依赖时，出现本插件精确送达消息再次作为新来源触发下一条平台回复。独立取证确认：原发送 ACK 仅带发送任务身份，真实消息身份在入站读取之后才持久确认；后续平台回复的发送许可没有再核自身来源。缓存与出箱投影的精确可见时点不可观测，不能指定唯一竞态。

还有引用资源错配：模型把当前消息ID与引用源资源ID一起交给DWS，实际引用源资源可以正常读取。资源工具仅增加精确补读指引，不伪造已读内容或自动扩大来源。

私有取证入口为ignored的`docs/tmp/semantic-latency/current-processing-14.json`中`ownNotificationTimeline`，观察时点2026-11-05T03:47:22.141Z。原14终态快照仍为03:24:10，不把窄取证当刷新了业务终态。原文、身份、凭据及完整事件不进入本快照。

## 候选比较

1. 只加入口过滤或发送前守卫：可以阻止部分后续答复，但不能收束已落账hold、已路由unit或重启后旧来源，也不能释放当前未知范围屏障。单独采用不足以完成目标。
2. 强行重路由为空、覆盖既有source.routed收据，或套用feature-removed退役：前两者破坏成功收据与来源事实，后者制造不真实的退役原因；不能用处理完成戳代替自身输出忽略。排除。
3. 在现有来源/退役链增加同群精确送达身份支持的own-notification退役事实，并在许可事务复核自身身份：能够保留原路由与真实效果、失效在途请求及恢复跨账中断。选择此方案，只增加当前已证缺口必需的合同。

现有`quarantined-echo-maintenance-recovery.md`针对旧事故的隔离节点/维护机制；`topic-source-authorization.md`针对真实用户续办授权，均不能表达本次迟识别来源的合法终态，故单独保留这份窄决策快照，不回改旧方案。

## 实施边界

- 身份依据只能是同群持久出箱/原生通知中精确送达messageId，沿用现有身份提取；不以账号、通用DWS标记、署名、正文或模型判断识别插件自身输出。
- Resident在既有群锁与版本门禁内记录必要退役事实，推进路由fence，使对应hold、活跃unit及旧请求不再产生新路由作用。保留原消息、历史Topic条目及旧成功决策/收据；历史内容不能继续充当当前人类授权。
- Dynamic source通过对应幂等命令追加真实退役事实，不伪造processingCompleted、不覆盖source.routed成功收据。纳入source.record身份重放、source.list/group.claim及投影，避免恢复后冲突或假性持续处理中。
- 两本账不假定原子；复用现有恢复执行链，使中断、重启和重复观察可补齐事实。未完成的跨账步骤必须可观察，不能静默吞错或假完成。只处理仍影响当前调度的精确自身来源，不增全库历史扫描或新维护平台。
- 新发送在现有许可事务内核对该库已确认的精确自身身份，迟识别不能绕过已准备通知继续发送。身份确认前已产生的效果、starting/unknown和delivered记录保留，不自动回滚、补发或重判；严格区分禁止新许可与撤销旧外部效果。 已接纳但未派发的内部计划不等于已发生的外部效果：原始来源精确绑定到自身消息时，沿既有来源失效路径保留schedule记录并置superseded，不另赋执行权；真实用户原预约按原始来源判断，不能因其确认回包是插件输出而受影响。
- 只修改完成此目标必需的核心文件、现有相关测试、README和对应运维说明；不改B唯一的coordinator文件，不扩大授权，不改全局最终通知quote:false策略，不新增模型选型、付费评测或CI。
- 持久化字段/命令是必要增量；是否涉及DDL需由实际实现核对，不先宣称无需迁移。合并和必要本机更新继续按既有Git与原生双包runbook，不热改安装目录或强停实例。

## 最小验证

覆盖迟识别时已入账hold、已路由unit与在途动作；真实身份确认后的prepared发送拒绝；旧成功收据、已发生发送及unknown保留；跨账中断/重启幂等；同账号非本插件消息不被忽略。验证与实际源码版本绑定，按影响运行相关回归及本地release-smoke，不扩全量或CI。

源码修复不等于当前14条完成。必要版本落地后，由C沿正式入口正常处理剩余依赖，D逐条核原14当前版本的decision覆盖、canonical source完成及原授权实际所需Task/通知终态。恢复回执、自身来源退役或看板数量下降均不能替代该验收。
