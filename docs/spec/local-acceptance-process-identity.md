# 本地验收进程身份校验

## 已确认问题

round-37-pid-reuse-probe.jsonl 第 20 次真实复现：短命 Node PID 6564 在北京时间 18:12:59 启动退出，旧遍历将当天 10:21:21 创建、ParentProcessId 同为 6564 的 PowerShell 与 conhost 视为当前后代。Windows PID 被复用，旧父 PID 关联不代表当前所有权。

## 最小方案

进程归属同时绑定 PID 与 CreationDate。根进程受本次启动下界与关闭时间约束；直接子进程不得出生于根生命周期以外，递归后代不得早于其父创建。排空回读比较相同 PID 的出生时间，复用 PID 不属于原进程。无法证明当前根身份不得执行 taskkill；真实当前子孙仍存活必须拒绝排空。

提取纯身份选择函数，确定性覆盖旧父 PID 关联、PID 不同出生时间、真实后代存活。继续实际 Windows 全链测试，不提高超时、不接受其他失败码、不跳过失败。原失败记录保留。产品修改完成后需要重新打包和部署；当前运行实例不会因源码编辑自动更新。
