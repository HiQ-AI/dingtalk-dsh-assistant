# Owner 应用阻塞的告知责任

已接纳决定连续应用失败达到现有预算后，报告仍为 application_status=blocked。现有通知仅处理 applied 报告，用户只能看到过期结果。

复用报告账与现有 owner 通知路径，增加 owner:application_wait:<reportId> 阶段。正文仅告知系统问题导致尚未继续，无需重复提交已有材料，不转发尚未应用的决定摘要。事件身份固定在报告，不含失败次数或技术原因。

发送领取核验最新已接纳 turn、应用仍 blocked、Owner 仍 blocked、当前需求与控制版本一致及原有消息来源守卫。恢复 discard/applied 或版本变化使 prepared 失效；已发送未知效果只回读，不重发。普通已应用报告合同保持不变。

验证同一阻塞重复扫描唯一告知，未执行摘要不泄漏，恢复后未发失效，未知发送恢复后仍只对账。
