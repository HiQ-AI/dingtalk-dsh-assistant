# 运行看板官方 UI 规范重构

## 目标

按 DeepSeek Harness Web UI 官方规范重构运行看板的群聊会话、授权审批、归档任务和告警四个页面，同时保持现有数据接口、任务动作与导航行为不变。

## 官方约束

- 复用 `@deepseek-ai/dsh-client-ui-primitives` 的 `Button`、`Pill` 与 `StateDot`；现有侧边审批详情保持原交互边界。
- 颜色、边框、背景、阴影和文字层级使用 `--dsw-*` 语义 Token。
- 不引入 Ant Design、Tailwind 或其他组件库。
- 页面通过现有 DSH Slots 组合，不新增独立路由或全局主题。

## 改动

- 增加统一的页面标题、说明、计数和空状态结构。
- 群聊会话保留常驻会话概览；群消息与 Outbox 合并为同一数据区，通过 Tab 切换，避免两张长表纵向堆叠。
- 群选择及消息/发件状态筛选放入数据区工具栏，筛选先于分页执行；授权审批同样在表格工具栏筛选状态。
- 所有页面保留页面标题、说明与数量，Header 只承担全局看板名称、运行态、一级导航和刷新。
- 页面、区块和组件之间统一为 24/20/16/12px 间距层级，并按新 Header 与页面标题高度重算任务列和视口高度。
- 授权审批使用官方状态组件和按钮，保留批准、拒绝与侧边详情能力。
- 授权详情侧栏统一为摘要头、分组正文和固定操作栏，关闭、拒绝、批准均使用官方按钮。
- 归档任务使用统一任务卡和完成状态语义。
- 告警使用 `StateDot` 表达当前异常与已恢复状态，筛选与分页沿用现有数据逻辑。
- 删除四页中重复的自定义胶囊、按钮和不一致的视觉状态。

## 验证

- Node 24 全量测试。
- 本地 DSH 安装包与源码哈希一致。
- 浏览器逐页切换，核对群聊、授权、归档、告警及授权详情交互。
