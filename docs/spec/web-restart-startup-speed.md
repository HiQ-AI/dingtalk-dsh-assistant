# 本地重启与初始化耗时

目标：定位桌面安全重启的脚本轮询和服务初始化分别耗时，减少检查自身成本；保留双端口同进程、原生排空/封存/快照、历史核验、维护恢复，不重复启动或打印凭据。

现状：桌面脚本320行仅存在本机；每轮全进程CIM和两次Get-NetTCPConnection耗时数秒。实测全进程923ms、单端口2194/699ms、原生监听快照11ms。用户本次Node21020创建23:10:55，登录日志写入23:13:19，初始化约145s，CPU28s，因此脚本轮询不足以单独解释全部启动延迟。候选为模块/文件冷加载、平台CLI凭据读取、渠道恢复；须实际取证后收敛。

方案：桌面入口仅委托正式脚本，源码进入scripts/restart-web.ps1，部署到DSH_HOME持久launchers避免改主检出；等待阶段先用.NET原生监听快照和HTTP，无监听不请求HTTP，不反复CIM/端口Owner/登录日志。最终就绪独立核验PID/双端口Owner及健康；停机也保留最终完整核验。计量初查/排空/服务就绪/恢复/总耗时，长初始化显示已等多久。

验证：隔离PowerShell测试跨进程/重复实例/HTTP未就绪拒绝、无监听轮询不枚举CIM或GetNetTCP、真正就绪一次完整核验、超时不重新启动；本机先Check零副作用，再受管真实重启取阶段计时与独立readback，保留未提交AGENTS.md。
