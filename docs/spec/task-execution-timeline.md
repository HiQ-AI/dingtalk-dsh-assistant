# 任务详情执行时间泳道图

仅任务详情展示，共用宿主主题与自然纵向滚动。顶部中性总览条按创建/重开至完成/取消分段（包括处理期间等待），完成至重开留白，不是累计运行时长；各执行会话独立一行，同会话续办保留空档，不同会话允许并行。最后一行为人工介入，无申请明确显示“暂无人工介入”。局部横向滚动可用键盘聚焦；原生折叠明细提供完整名称、活动、时间与申请问题，兼容触屏和屏幕阅读器。日期沿宿主浏览器时区与 zh-CN。

## 现有证据与最小补全

当前生效入口为 task-session-service → dynamic-task-store；Observer 的 TaskSessionDetail 使用 `/state/tasks/:id/detail`。不使用旧 workflow。现有 `runTiming` 只有累计时长和当前领取起点，不能还原完整区间；`stageProgress` 是最新快照，但 `dynamic_wakes` 的 `execution.stage.progress` 已持久保留各次成果的 summary、recordedAt、执行/输入/租约身份。复用这些 wake 在折叠明细展示阶段成果，图中以贯穿色带、上下各超出 3px 的轻细刻线展示，各不同时间严格映射统一时间轴，固定同一水平线，不做位置避让；同一时刻可共享位置并保留全部内容；无圆点或数量角标，命中区可较大，悬停/聚焦列出附近成果准确时间与内容，不新增重复成果日志，不从成果摘要或最终摘要推算过去的活动时长。

执行 JSON 增加 Host 管理的 `timeline: {version:1,complete,segments}`，无数据库 schema 迁移。dispatch 初始化空记录；claim 开始区段；首次 result 或无结果 drained 关闭。排空等待与排队不算执行。取消请求尚未排空仍保留活动区间。continue、供应商退避重试及恢复沿用原执行身份，下次 claim 才开新区段。

初始活动名使用已持久中文会话短名。现有 `execution_report_progress` 可选 `activity`（1–120 字），仅用于声明从报告提交时刻开始的业务活动，例如“查询信息”“修改配置”“验证修复”；Host 验证租约和当前输入后，以当前时间关闭前段、开启后段。同名不重复切分，无 activity 的原成果报告行为保持不变。此采集不决定任务完成、不发送消息、不授权业务操作。新阶段尚未报告前只展示已知的小目标名称，不虚构更细阶段。

重启发现仍开放的区段标为 unknown，保留起点但不以恢复时间冒充终点；投影不绘制未知长度区段，显示部分区间未记录。历史无字段保持不完整，后续 claim 只采集新证据，不回填历史。时钟倒退同样保留未知标记。已封口区段不变。

详情 API 的 timeline 独立读取本任务全部执行，不受执行详情分页 50 条限制；按会话归并。看板 DTO、其他页面和现有运行时长口径不变。阶段成果来自同任务绑定执行的持久 wake。

人工介入只读取任务自身 humanRequests。createdAt 为开始，waiting-reply 延伸当前；answeredAt、supersededAt、cancelledAt、closedAt 分别用于已答复、已失效、已取消、已关闭。当前账本主要产生前两种终态；兼容字段存在才展示其它终态。不把任何终态当作批准，不使用通知发送、撤回或普通 updatedAt 作为处理终点；历史缺开始/对应结束时间不画区段。task.control 的取消事务补记 cancelledAt，以提供任务总条的真实取消时间；旧取消任务不回填。

参考像素由父线程通过 Library 原生 materialization 核验；本云环境授权下载返回 403，未读取图片像素。实现依据父线程已核验的结构说明。验证使用隔离 SQLite、脚本模型和浏览器 API；不代表生产实机、真实模型或钉钉通道验收。


## 任务完成与重开

任务总览使用连续时间轴，按创建/重开至完成分段，完成至重开留白；当前区段延伸至现在，终态固定。总览文字区分“已完成”“重开后完成”“重开后处理中”，详情展示真实创建、完成与重开时间，不增加小竖线。每个区段时长仅以其自身结束减开始计算；进行中区段使用 now，完成区段固定，不跨越完成至重开的空档。人工区段明确为等待历时，任务区段为本次处理历时。宽区段名称/时长同排，窄区段优先时长；悬停和聚焦提示及折叠明细提供完整信息。

只读使用当前 completion.at、task.reopen wake，以及不可变重开回执和 complete:taskId:requirementRevision 完成回执；核验任务、修订及既有 runSequence。缺失或异常事实标记历史不完整，不用摘要、updatedAt 或通知时间推断。不增加表、实体或写入，也不改变统筹判断及重开门禁。
