# 工作流托管变量与凭据

日期：2026-10-13。用户在工作流目录实施期间追加：普通配置与凭据统一支持，并新增独立「配置」Tab。该方案是新增范围的开工快照。

## 目标与当前约束

变量内容进入宿主管理的持久存储，流程绑定变量名而不是任意本地文件路径。执行冻结精确版本并在 Host 读取；移动用于提供初始内容的文件后，已保存变量与已冻结执行仍可读取。配置 UI 不等同自动迁移所有旧脚本/平台文件：已有消费点只有明确改为托管引用后才脱离原文件。现有 schema、目标白名单和执行授权不得被变量内容绕开。

当前 @deepseek-ai/dsh-credentials 0.1.2-rc.1 提供 readRecord / modifyRecord / describeRecord；record 空间不从环境变量覆盖，modifyRecord 是跨进程锁内读改写。默认 credentials-local 是原子替换的明文 YAML，Windows 不提供额外加密隔离。本轮复用该正式服务，不自建保险库，不声称秘密已加密，也不读写真实凭据。

三种持久化方案：仅保存旧文件路径无法解决移动问题；普通域与凭据库分写会产生跨库发布事务；采用插件私有 native grant record 保存版本化配置文档，可在单个 modifyRecord 中完成 CAS 与发布，简化一致性。记录有明确大小和数量上限，Web 仅接收脱敏投影；秘密和普通变量均不写入执行事件/工件。

## 数据与版本合同

- 插件自有固定 credential record；变量有 name、description、kind（普通/secret）、format（text/json）、revision、enabled 和不可变版本值。名称和种类创建后不可更改，秘密不可降级为普通变量。
- 配置文档有 revision；所有管理修改必须提交 expectedRevision，过期拒绝 409，错误只返回稳定机器码。每个操作原子发布并返回脱敏最新视图；秘密值不出现在读取、保存回执、日志或错误。
- 工作流绑定 aliases → variable names；绑定只允许已登记目录工作流及已存在启用变量。变量更新不直接改旧执行：冻结时取绑定和变量当前 revision，之后只按这些版本读取。
- 执行快照独立存入不可变 native record，地址从受信 runId 与 workflowId 导出。创建 Run 之前冻结；相同 Run 重投读取相同快照。缺少旧快照不能回退为最新配置。
- 停用阻止新的绑定与执行快照；已经冻结的版本保留，页面明确这个含义。不物理删除历史版本，不伪装即时撤销。
- 每个变量值不超过 64 KiB，活动变量不超过 100 个，配置文档不超过 4 MiB；超限明确拒绝。无无限追加日志。

## 读取与权限合同

- 配置页请求均为本机来源，拒绝不许可的 Origin / Host 与客户端自报 actor。Resident 注入已配置 webActorId，服务复核；读取普通变量值也受同样边界。
- Host API 提供 snapshot({runId, workflowId})、forRun({runId,workflowId})；只允许该流程快照已绑定 alias。普通读取和 secret 读取分开，返回数据仅给受信节点代码，secret 不进入模型上下文、输入工件或工具参数。
- 执行器只给 code executor 传 configuration reader；注册表归一化工程派生 ID，其他未知流程拒绝。旧 Run 不隐式冻结最新变量。变量能力未接入时明确不可用；无绑定流程保持原行为。
- 变量 API 不支持任意文件路径读取、环境变量替换、任意凭据 record key 或自由执行代码；不修改既有数据库/平台目标授权。
- 原文件依赖通过受信消费适配器逐点替换；优先接通数据库 connector 的受信连接配置读取，配置值仍须验证 host/port/database/user/password 结构，密码保留 Host。

## 页面与操作

在「工作流」旁增加「配置」。列表展示名称、类型、当前版本、启用状态和引用流程；普通值可查看/编辑，秘密只显示已设置，替换时重新输入，默认隐藏并可切换可见性。空白不隐式删除秘密；取消/失败/版本冲突不丢当前输入，返回后通过明确操作重新读取当前版本。

复用宿主 Button、现有 SelectMenu 与表单主题。创建与编辑在页面内进行；无 browser alert/confirm/prompt。离开未保存表单提供页面内保存/放弃选择；停用明确后果并二次确认。读取错误独立重试；切换页面/选中项不接受过时响应。工作流详情显示引用别名、变量名、类型与当前版本，并跳到配置页对应项。配置页绑定通过已有工作流目录选择，不允许任意 workflowId。

## 验证与完成边界

定向单元/API 测试覆盖普通/secret、JSON、CAS、停用、绑定校验、跨流程拒绝、秘密脱敏、旧版本固定、新执行采用新版本、重试与重启读回。使用正式 native provider 的隔离路径验证持久化；导入隔离文件后移动源文件、重新创建 service/Host 并实际执行读取路径，证明不是内存缓存或旧路径回退。

真实 React + headless Edge 验证两个新页面的创建/编辑/绑定/停用/秘密遮蔽、错误/冲突保留、键盘和窄屏。证据沿 docs/acceptance/workflow-dashboard/ 保存，round 递增、matrix 为状态源。无需自动导入正式文件、部署或触发真实数据库/发布动作。
