# 看板刷新时保留页面

目标：任务看板在自动、手动刷新，以及宿主重挂载后保持所选页面；同一标签页整页重载后重新打开看板也恢复该页面。

当前 ObserverContent 用 `useState('groups')` 初始化页面，五秒轮询只写数据，不直接切页。当前 DSH 的 conversation 为 session-maybe 插槽，宿主会话切换或暂时为空时会重挂载子组件，丢失组件内页面状态。普通同会话重渲染使用稳定组件，不应误归因为 openSession 回调变化。现场 Web/Runtime 端口未监听，尚不能确认用户现场是哪种宿主刷新触发了重建。

复用现有 pages 和所有 setActivePage 调用，在当前标签页的 sessionStorage 只存页面 ID，初始化时校验合法值；存储不可用时仍允许浏览与数据刷新。不修改宿主插槽、业务 API、布局或业务数据。任务详情、筛选和分页的持久化不在本次页面导航修复范围。

验证使用完整 Observer 与真实 React、独立无头浏览器，隔离宿主及数据接口：旧源码复现重挂载回群消息；新源码验证自动/手动刷新、宿主重挂载、整页重载、其他页面、错误/空态、键盘及窄屏。相关 Node 测试另行执行。隔离验证不等同于本机部署及真实宿主验收。
