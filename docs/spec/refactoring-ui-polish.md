# 插件页面视觉尺度与适配优化

## 目标

仅落实 Refactoring UI 审查中的两组改进：统一字号、间距、圆角和阴影尺度；补齐响应式布局、可操作空状态与键盘焦点态。

## 范围

- 运行看板统一使用 12/14/16/20px 字号、4/8/12/16/24/32px 间距和 8/12px 圆角。
- 插件设置页复用相同尺度，并为窄宽度下的状态行、搜索行和操作行增加换行能力。
- 运行看板在 960px、720px 下调整页面留白、话题双栏和任务列数；宽表保留可访问的横向滚动容器。
- 所有可交互元素增加清晰的 `:focus-visible` 样式。
- 数据为空且存在恢复路径时，空状态提供说明和刷新操作。

## 非目标

- 不调整页面导航和设置页信息架构。
- 不改变任务卡内容、任务状态分栏、接口或运行时数据。

## 验证

- 运行现有 client/observer 前端测试及构建生成检查。
- 本地部署后检查宽屏与 960px、720px 视口，覆盖设置页、群聊消息、话题、任务看板和空状态。
- 使用键盘确认导航、按钮、表单和折叠项均有可见焦点。
