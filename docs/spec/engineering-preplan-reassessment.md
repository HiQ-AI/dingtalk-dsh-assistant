# 工程准备失败后的原任务重评

2026-10-08 原 Task 已读取文档并接收 UAT2，Owner advance 在创建工程计划前因配置源仓库目录不存在返回 Git128。源仓库现已恢复，但 readonly reassess 只支持两种特定被拒候选，通用的 blocked advance 被拒；retry-owner仅用于无决定/超时，不能冒用。

采用既有维护者重评入口：仅当 blocked advance 未形成计划接纳收据、计划阶段、执行 Run/节点或外部效果，且 Owner/租约/需求/控制版本、来源及排空证据全部通过时，废弃该未生效候选并让同一个 Owner重新评估。不能仅根据128字符串推断安全。正常只读证据重评、既有成功外部阶段恢复及其他拒绝路径保持。

排除直接改控制库（破坏审计）、伪造需求补充（改变用户来源）、将128列为自动重试（覆盖未知Git副作用）。只修恢复准入，不替业务执行器修改功能代码。验证必须覆盖零阶段恢复、重复幂等以及任一收据/阶段/Run/效果与来源版本冲突拒绝。
