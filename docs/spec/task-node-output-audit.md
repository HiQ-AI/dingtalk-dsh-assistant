# 当前任务节点产出逐项核对

## 范围与现状

用户要求逐个核对节点产出。以当前实例任务详情包含 outputRef 的 37 个节点为实证，覆盖材料分析及工程链 20 类节点；同时核对对应当前源码契约。可选发布/数据变更流程未在这批实际任务中运行，不冒充已有线上证据。

## 逐项展示规则

| 节点 | 已存产出 | 展示规则 |
| --- | --- | --- |
| prepare / prepare-generation / prepare-workspace | 任务要求、约束、材料或基线 | 要求与材料，基线作为版本信息；不捏造目录产出 |
| analyze / validate-result | 摘要、限制、证据引用 | 实际结果，校验节点保留相同结果，不捏造额外报告 |
| index-files | 目录索引、文件数、排除数 | 默认索引与排除数量，展开清单 |
| select-files / validate-selection | 已有、新建、选定路径 | 默认各类去重文件数，展开清单 |
| read-files | 文件正文与读取快照 | 默认读取/不存在数量，展开文件清单 |
| propose-changes / inspect-and-propose | 完整修改或局部替换方案 | 默认方案涉及的去重文件数，展开真实修改内容 |
| apply-changes | 编辑回执及文件哈希 | 默认修改数量；不能标成已读取 |
| verify-candidate | 冻结候选、检查结果 | 检查总数与通过数，展开逐项结果，隐藏日志 |
| prepare-commit / prepare-push | 提交/推送计划、变更清单、检查结果 | 明确准备状态、文件数、分支；不当成已执行 |
| commit / push | prepared + receipt | 回执状态、分支及版本；文件数与内容折叠 |
| prepare-pr | PR草稿 | 草稿标题、目标分支，正文按需展开 |
| create-pr / finalize | PR回执或回读 | PR编号/地址及状态，不能当作已合并或部署 |

## 实施与验证

复用 workflow-service 内只读产出投影，将纯转换提取为可定向验证的导出函数，不新建服务。接口保留鉴权、引用一致性与分页，附加轻量 overview；详情仅展开后渲染正文。文件数量根据完整工件去重，不依据当前页推算。未知结构说明已保存但尚无可读展示，不能说没有产出。

实跑每类投影、长清单/分页/去重及安全字段测试；当前 37 个实际工件逐一只读核对投影和展示摘要，记录节点类型与结果，不保存业务正文。浏览器验证默认折叠、展开、分页、收起、窄屏及错误重试。部署后回读真实方案、修改、提交、PR节点；不重放业务。
